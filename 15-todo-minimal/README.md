# 15-todo-minimal

## 目的
フロント（ブラウザ）からバックエンドAPIを呼び出す最短導線を作り、
「画面操作 -> API呼び出し -> サーバー処理 -> 画面反映」の流れを理解する。

## この章で達成したいこと
- バックエンドに最小APIを1本作る（例: `GET /hello`）
- フロントから `fetch` でAPIを呼ぶ
- 返却JSONを画面に表示する
- 実行基盤（ポート、起動、CORS）を説明できる

## 最小ステップ
1. バックエンドで `GET /hello` を実装する
2. `localhost:8080` で起動し、`curl` で疎通確認する
3. フロントに `index.html` を1枚作る
4. ボタンクリックで `fetch("http://localhost:8080/hello")` を呼ぶ
5. レスポンスJSONを画面に表示する
6. 必要ならCORSを許可して成功/失敗を比較する

## 完了条件
- ブラウザからAPIを呼んで、画面に結果を表示できる
- 処理の流れを自分の言葉で説明できる
