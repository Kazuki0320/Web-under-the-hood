# 16-http-vs-websocket

## 目的
HTTP と WebSocket の違いを、握手・接続維持・双方向通信の観点から実装ベースで理解する。

## この章で達成したいこと
- HTTP は `request -> response` 型だと説明できる
- WebSocket は `Upgrade` 後に双方向通信へ切り替わると説明できる
- どの用途なら HTTP / WebSocket のどちらを選ぶべきか判断できる

## 最小ステップ
1. HTTP で `GET /hello` を返す最小サーバーを作る
2. WebSocket の `Upgrade` 握手を通す最小実装を作る
3. HTTP と WebSocket の通信の流れを比較する
4. ブラウザや `curl` で挙動を確認する
5. 違いと用途をメモにまとめる
