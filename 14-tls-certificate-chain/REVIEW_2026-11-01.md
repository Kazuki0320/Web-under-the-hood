## 間違っていた部分

### ① 2行目: import のパッケージが違う

書いたコード:
```java
import java.net.SocketFactory;
```

何が違う:
- `SocketFactory` は `java.net` ではなく `javax.net` にある。
- そもそも今回使うのは子クラスの `SSLSocketFactory`（`javax.net.ssl`）なので、`SocketFactory` の import は不要。

正しいコード:
```java
import javax.net.ssl.SSLSocket;
import javax.net.ssl.SSLSocketFactory;
```

覚え方:
- `java.net.Socket` … 03章で使った普通のTCPソケット
- `javax.net.ssl.〇〇` … TLS関係はここにまとまっている

### ② import が足りない（`SSLSocketFactory` / `SSLSocket`）

何が起きる:
- import していないクラスは、Javaが見つけられず `cannot find symbol` になる（実際にこのエラーが出る）。

正しいコード: ①と同じ2行を追加する。

### ③ 29行目: ファクトリの取り方が違う

書いたコード:
```java
SSLSocketFactory factory = SocketFactory().SSLSocketFactory.getSession();
```

何が違う（3点）:
1. `SocketFactory()` は存在しないメソッド。クラス名の後ろに `()` を付けても呼べない。
2. `getSession()` はファクトリではなく、ハンドシェイク後の `SSLSocket` が持つメソッド（Step 4 で使う）。
3. ファクトリを取るのは `getDefault()`。戻り値が親の型（`SocketFactory`）なので、`(SSLSocketFactory)` でキャストする。

正しいコード:
```java
SSLSocketFactory factory = (SSLSocketFactory) SSLSocketFactory.getDefault();
```

読み方:
- `SSLSocketFactory.getDefault()` …「SSLSocketFactory クラスの getDefault を呼ぶ」（static メソッドはクラス名.メソッド名 で呼ぶ）
- `(SSLSocketFactory)` …「返ってきた物を SSLSocketFactory として扱う」

### ④ 考え方: 親クラスと子クラスは `.` でつながない

29行目の `SocketFactory().SSLSocketFactory` は、「親の中に子が入っている」と考えて書いたように見える。

実際は:
- 子クラス（`SSLSocketFactory`）は、親（`SocketFactory`）のメソッドを **最初から自分で持っている**。
- そのため、親を経由せず `SSLSocketFactory.getDefault()` と子のクラス名から直接呼ぶ。
- `.` は「その物が持っているメソッドやフィールドを呼ぶ」記号で、親子関係をたどる記号ではない。

```text
× 親.子.メソッド()        例: SocketFactory().SSLSocketFactory.getDefault()
○ 子クラス名.メソッド()    例: SSLSocketFactory.getDefault()
○ 変数.メソッド()          例: factory.createSocket(host, port)
```

### ⑤ 30行目: メソッド名が抜けている

書いたコード:
```java
try (SSLSocket socket = (SSLSocket) factory.(host, port)) {
```

何が違う:
- `factory.` の後ろにメソッド名がない。ソケットを作るメソッドは `createSocket`。
- コンパイル時に `<identifier> expected`（ここに名前が必要）というエラーが出る。

正しいコード:
```java
try (SSLSocket socket = (SSLSocket) factory.createSocket(host, port)) {
```

### ⑥ try の中が空で、return が try の外にある

今は途中なので問題ではないが、完成形では:
- Step 2〜4 は try の中（ソケットが開いている間）に書く。
- 証明書チェーンの `return` も try の中で行う（抜けるとソケットは自動で閉じる）。

## 正しいコード（完成形）

```java
import java.security.cert.Certificate;
import java.security.cert.X509Certificate;
import javax.net.ssl.SSLParameters;
import javax.net.ssl.SSLSession;
import javax.net.ssl.SSLSocket;
import javax.net.ssl.SSLSocketFactory;

// （中略）

static X509Certificate[] fetchCertificateChain(String host, int port) throws Exception {
    // Step 1: TCP接続（ソケットを作った時点でつながる）
    SSLSocketFactory factory = (SSLSocketFactory) SSLSocketFactory.getDefault();
    try (SSLSocket socket = (SSLSocket) factory.createSocket(host, port)) {
        System.out.println("TCP接続: " + socket.isConnected());

        // Step 2: ホスト名検証をオンにする
        SSLParameters parameters = socket.getSSLParameters();
        parameters.setEndpointIdentificationAlgorithm("HTTPS");
        socket.setSSLParameters(parameters);

        // Step 3: TLSハンドシェイク（証明書が届き、Javaが検証する）
        socket.startHandshake();

        // Step 4: 接続情報と証明書チェーンを取り出す
        SSLSession session = socket.getSession();
        System.out.println("TLS: " + session.getProtocol());
        System.out.println("暗号スイート: " + session.getCipherSuite());

        Certificate[] certificates = session.getPeerCertificates();
        X509Certificate[] chain = new X509Certificate[certificates.length];
        for (int i = 0; i < certificates.length; i++) {
            chain[i] = (X509Certificate) certificates[i];
        }
        return chain;
    }
}
```

※ このコードはコンパイルが通ることを確認済み。example.com への実際の接続は未確認（こちらの環境の制限）。
