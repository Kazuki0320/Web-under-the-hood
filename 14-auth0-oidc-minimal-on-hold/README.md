# 14-auth0-oidc-minimal

## 目的
Auth0 の最小構成をローカルで通し、OIDC 認可コードフローを実装ベースで説明できる状態にする。

## この章で達成したいこと
- ログイン -> コールバックまで疎通できる
- `ID Token / Access Token` を取得できる
- `iss` / `aud` / `exp` を確認できる
- Access Token の検証（署名・期限）を説明できる

## 最小ステップ
1. Auth0 テナントとアプリを作成する
2. Callback URL / Logout URL を設定する
3. ローカル最小アプリを起動してログインを通す
4. コールバックで受け取るトークンを確認する
5. Access Token の検証処理を追加する

## 完了条件
- ローカルで `ログイン -> コールバック -> トークン検証` まで再現できる
- 実行ログと設定値をこの README に記録できる
